주요 기능

멘션으로 바로 호출

명령어 없이 D-AI를 멘션하기만 하면 바로 대화가 시작돼요.

필요한 도구는 알아서

질문에 따라 검색, 시간 조회 같은 도구를 스스로 판단해서 사용해요. 앞으로 다른 도구도 계속 추가될 예정이에요.

대화 기록 기억

사용자별로 최근 대화 흐름을 기억해서 이야기를 이어갈 수 있어요.

/초기화 로 언제든 새로 시작

안전한 답변 필터링

욕설이나 부적절한 표현 없이, 누구나 안심하고 대화할 수 있어요.

상태 확인

/핑 명령어로 지금 쓰고 있는 모델, 응답 속도, API 연결 상태를 한눈에 볼 수 있어요.

한국어 중심 응답
